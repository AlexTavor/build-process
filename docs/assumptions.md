# Assumptions

Beliefs mlmd's design stands on that nobody has proved. A high-fragility entry gets a spike, or a
decision that makes it not matter, before anything is built on it.

| # | Assumption | Falsified if | Detector / verify by | Fragility | Fallback |
| --- | --- | --- | --- | --- | --- |
| A1 | The trust boxes' `ask` permission rules stop the merge, push and release commands in every permission mode, and in every form the agent may write them. | A covered command runs without asking, in some mode or some form. | Spike [trust-enforcement](spikes/trust-enforcement.md), 2026-09-30: **no for the ask rules, yes for a PreToolUse hook.** An ask rule stops only commands that start with its text: 4 of 12 forms. A plain `git push` and `git push -u origin` ran with no question. A hook that reads each command asked for all 12 forms in all five modes, on 2.1.165 and 2.1.284, bypass included. Run without the model; auto mode's three rules-only cells and the question on screen are still to check. | High: without it, the trust boxes are settings nothing enforces. | A PreToolUse hook that reads each command and asks. Bypass mode documented as every box unchecked. |
| A2 | A session can move from one item's worktree, beside the repository, into the next item's worktree, including after `/clear`. | Claude Code refuses the second move. | Spike [worktree-switching](spikes/worktree-switching.md), 2026-09-30: **yes, one way.** A direct move between worktrees beside the repository is refused. ExitWorktree, then EnterWorktree with the item's name through mlmd's WorktreeCreate hook, works on 2.1.165 and 2.1.284, also after `/clear`, and asks nothing. Run headless without the model; `/clear` typed by hand is still to check. | Medium: the `/clear` then `/mlmd:next` loop depends on it. | Worktrees under `.claude/worktrees/`, with each tool excluding that folder; or a new session per item. |
| A3 | The desktop app's worktree option calls the WorktreeCreate hook, and the app's diff, base-branch sync and archive work with a worktree the hook made. | The app makes its own worktree without calling the hook, or one of those features breaks. | Spike [desktop-worktree-hook](spikes/desktop-worktree-hook.md), in progress. Attempt 2: the app calls the hook, but the hook's process can't reach `~/Documents`. Attempt 3, outside `~/Documents`, is next. | Medium: the desktop half of the worktree design depends on it. | The app's own worktrees, with the SessionStart hook fixing the branch's base, its name and its dependencies. |
